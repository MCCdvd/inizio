📊 7-RUN BENCHMARK QUICK START
==============================

PROBLEM:
  DQN returned +9.01% one run, +0.56% the next on same data
  = Results are random without fixed seed
  
SOLUTION:
  Run each algorithm 7 times with fixed seeds, calculate stats

USAGE:
  # Simplest approach
  chmod +x benchmark_7runs.sh
  ./benchmark_7runs.sh

  # Or Python directly
  python benchmark_7runs.py

  # Custom options
  python benchmark_7runs.py --stock MSFT --episodes 250

OUTPUT:
  benchmarks/
  ├── benchmark_results_20260828_130000.csv     # All 21 runs
  └── benchmark_statistics_20260828_130000.csv  # Aggregated stats

WHAT YOU GET:
  ✓ Mean return ± std dev for each algorithm
  ✓ Min/max range across 7 runs
  ✓ 95% confidence intervals
  ✓ Sharpe ratio statistics
  ✓ Trading metrics (trades, win rate, profit factor)
